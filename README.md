# Luxe Nails Website

Premium static website for Luxe Nails, built specifically for GitHub Pages.

## Publish on GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**.
4. Save.

GitHub will publish the site at:

`https://probuilderoffical.github.io/luxenails/`

## Notes

- No build step or framework is required.
- The site is responsive and optimized for mobile.
- Current business/contact information is intentionally linked to the official Google profile instead of duplicating time-sensitive details.
- Visual imagery is loaded from Pexels CDN and fonts from Google Fonts.
